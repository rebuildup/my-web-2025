# GitHub Delivery

Read `docs/agent/release-workflow.md`. Use `release-x-y-z` for sprint integration and the Issue number alone for a ticket branch. Keep Issue/PR/review text in Japanese and commit messages in English. Do not mark a ticket Done before merge and required checks.
